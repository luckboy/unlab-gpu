## GitHub configuration file

A [GitHub](https://github.com) configuration file is the `github.toml` file that is in the Unlab-gpu
home directory.

## GitHub configuration file format

A [GitHub](https://github.com) configuration file format is based on the
[TOML](https://en.wikipedia.org/wiki/TOML) format. The `api-version` field can be in the the
[GitHub](https://github.com) configuration file and specifies the API version of
[GitHub](https://github.com) service.
